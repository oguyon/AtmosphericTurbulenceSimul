# Feature Planner

This skill guides the agent through scoping, planning, and getting approval for features or
architectural refactorings.

## Feature Design Workflow
1. **Research & Requirements:** Understand the goal, locate affected files, and analyze
   cross-module dependencies.
2. **Draft Plan:** Put together the technical changes in an artifact or implementation plan
   using `templates/feature-plan-template.md`.
3. **Review:** Present the plan to the user for feedback.
4. **Iterate:** Address feedback until the plan is approved before making wide edits.
